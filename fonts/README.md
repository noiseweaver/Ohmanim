# Fonts

Fonts used by `Text` in the editor preview and in the in-browser Manim render. `fonts.json` lists them; `files/` holds Regular and Bold TTFs.

- DejaVu Sans, Sans Mono and Serif: Bitstream Vera / DejaVu licence (`LICENSE-DejaVu.txt`).
- All others come from [Google Fonts](https://fonts.google.com) (via the `@expo-google-fonts` npm packages) under the SIL Open Font License 1.1 or Apache 2.0, as listed on each family's Google Fonts page.

Characters missing from a font (for example Ω in Caveat or Lato) fall back to DejaVu Sans.
